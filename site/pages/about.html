About PSVR2-DriverKit

PSVR2-DriverKit is an independent, open-source project that brings the PlayStation VR2 to Linux as native code, for both SteamVR and OpenXR.

Built on

  • Monado (BSL-1.0): the OpenXR runtime this project is built on, including the PS VR2 headset and Sense controller drivers it extends.
  • ALVR (MIT): reference for the SteamVR driver's structure and the controller hand skeleton.
  • PSVR2Toolkit (MIT): reference for SteamVR's camera interfaces, the PS VR2 properties SteamVR expects, and eye tracking in SteamVR.
  • Mercury (Moshi Turner and Collabora, part of Monado): the hand tracker.
  • WayVR (GPL-3.0): the separate desktop overlay the driver can start.
