PSVR2 with OpenXR on Linux

PSVR2-DriverKit includes a fork of Monado, the open-source OpenXR runtime, with the PS VR2 and Sense controller drivers. Native Linux OpenXR apps run on it directly, without SteamVR.

What OpenXR apps get

FeatureStatus
Headset 6DoF, distortion, IPDStable
Sense controllers: 6DoF, inputs, hapticsStable
Eye gaze (XR_EXT_eye_gaze_interaction)Works (no per-user calibration)
Bare-hand trackingExperimental
PassthroughNot available

Launch an app

In DriverKit: Launcher → Start monado-service, then Launch app.

In a terminal:

~/.local/share/PSVR2-DriverKit/kit/launch-openxr.sh /path/to/openxr-app

The script starts monado-service, points the app at it with XR_RUNTIME_JSON, and stops the service when the app exits.

SteamVR or Monado?

Use SteamVR for SteamVR games, Proton games, Room View and room setup. Use Monado for native Linux OpenXR apps without SteamVR. Only one can use the headset at a time.
