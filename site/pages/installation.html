Install the PSVR2 driver on Linux

About 15 minutes, most of it compiling. The PSVR2-DriverKit app does the work; you press four buttons.

Before you start

  • Steam and SteamVR from your distribution's native Steam package. Flatpak and Snap Steam aren't supported. Start SteamVR once so it creates its settings.
  • The PS VR2 on Sony's PC adapter, connected to a DisplayPort output and a USB port.
  • Recommended: Sony's free PlayStation VR2 App from Steam, installed before compiling, so SteamVR shows the real Sense controller models.
  • Pair the controllers in your Bluetooth settings: hold Create + PS until the light flashes.

1. Get the app

AppImage (easiest)

Download PSVR2-DriverKit-x86_64-<version>.AppImage from the latest release, then:

chmod +x PSVR2-DriverKit-x86_64-*.AppImage
./PSVR2-DriverKit-x86_64-*.AppImage

Or from source

git clone https://github.com/mkooner/PSVR2-DriverKit.git
cd PSVR2-DriverKit && ./install-deps.sh
cd launcher-gui && cargo build --release
./target/release/PSVR2-DriverKit

2. In the Compile Driver tab

  1. Install dependencies. Installs the build packages with pacman, apt or dnf, and the udev rules that let you open the headset and controllers without root. It asks for your password.
  2. Compile Driver. Downloads the latest source and builds the SteamVR driver, monado-service and a fresh DriverKit into ~/.local/share/PSVR2-DriverKit. Afterwards DriverKit runs from <install folder>/kit.
  3. Register our driver. Steam now starts SteamVR with the PS VR2.
  4. Turn on PS VR2 features (once, SteamVR closed): Room View and the wall camera.
Optional: Allow high priority (SteamVR features) lets SteamVR's compositor use a high-priority GPU queue, which async reprojection needs. It's your choice and isn't done by default.
Hand tracking (experimental): tick Compile hand tracking before Install dependencies. It needs Debian 13, Ubuntu 25.04, Fedora 43 or newer, or an Arch-based system.

3. Play

Start SteamVR from Steam, or a VR game. On the first start, draw your play area from the SteamVR dashboard's Playspace menu, and hold the controllers in front of the headset for a few seconds.

Updating and uninstalling

To update, press Compile Driver again. To uninstall, press Unregister, then delete ~/.local/share/PSVR2-DriverKit and ~/.config/PSVR2-DriverKit.

Stuck? See troubleshooting. The full technical guide is in the repository docs.
