Download PSVR2-DriverKit

PSVR2-DriverKit is free and open source. The app compiles the driver on your PC, so it always builds the latest version.

AppImage

Get PSVR2-DriverKit-x86_64-<version>.AppImage from GitHub Releases:

Latest release All releases

Make it executable (chmod +x) and run it, then follow the installation steps.

Source code

git clone https://github.com/mkooner/PSVR2-DriverKit.git

Licensed under the Boost Software License 1.0, like Monado.

Updates

Press Compile Driver in your installed DriverKit to update to the latest version. Release notes are on the releases page.
