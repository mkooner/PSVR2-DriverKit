PSVR2 with SteamVR on Linux

PSVR2-DriverKit's native SteamVR driver presents the PS VR2 and Sense controllers to SteamVR. Steam starts it like any headset, from the Library or from a VR game.

Setup

  1. Install and compile (see installation).
  2. DriverKit → Compile Driver → Register our driver.
  3. Turn on PS VR2 features for Room View and the wall camera.
  4. Start SteamVR. Or use DriverKit → Launcher → Start SteamVR for pre-flight checks (udev rules, controller connections, GPU queue, conflicting programs) and a log summary afterwards.

What SteamVR gets

  • The headset: 6DoF tracking, distortion, IPD, wear sensor, eye tracking, and the function button for Room View.
  • The Sense controllers: 6DoF, every input including touch and finger distance, haptics, a finger skeleton, and the PS button for the dashboard.
  • PS VR2 bindings for SteamVR, and layouts for older games: Oculus Touch by default, or Vive, Index or native.
  • Room setup from the dashboard's Playspace menu.
  • Sony's controller models and icons, when the PlayStation VR2 App is installed.

Windows games through Proton

Start SteamVR first, then the game. Games need OpenVR or OpenXR support; UMU-Proton works best for VR.

Limitations

  • Async reprojection needs SteamVR's high-priority GPU queue (Allow high priority) and isn't available on Intel Arc.
  • SteamVR's own Desktop panel is blank on Wayland (a SteamVR issue). See Wayland for WayVR.
