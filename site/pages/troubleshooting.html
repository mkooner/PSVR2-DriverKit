PSVR2 Linux troubleshooting

Start SteamVR from DriverKit → Launcher → Start SteamVR: its pre-flight list catches most problems, and it collects logs in ~/.local/share/PSVR2-DriverKit/kit/logs/ when SteamVR exits.

Controllers aren't found

  • No udev rules: press Install dependencies, then turn the controllers off and on.
  • Paired but not connected: press PS on each controller.
  • Never paired: hold Create + PS until the light flashes, and pair it in Bluetooth settings.

"Something already holds the headset"

Close SteamVR or a running monado-service. A leftover Sony driver helper from Wine/Proton: pkill -f ignition_server.exe.

Flicker or judder when frames are late

  • Press Allow high priority (Compile Driver → SteamVR features), so SteamVR can use async reprojection.
  • Intel Arc can't get async reprojection on Linux. Lower the game's settings or the render size.

SteamVR crashes with Room View (Intel Arc)

Set Settings → Headset cameras in SteamVR to off.

Compile Driver fails

Press Install dependencies first. For hand tracking, your distribution needs onnxruntime packages. Attach compile.log from the install folder to an issue.

A game opens on the desktop

Start SteamVR first, then the game. For Windows games, use UMU-Proton, and check that the game supports OpenVR or OpenXR.

Still stuck?

Open an issue with the zipped logs folder. The complete list is in the troubleshooting documentation.
